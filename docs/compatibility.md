# 硬件兼容性与已知限制

## 目标硬件与接口参数

Rainy75 V2 内部由两颗独立的 MCU 分别负责键盘和屏幕，刷机文件和升级入口完全分开：

| 组件 | 芯片 / 接口 | 关键参数与版本要求 |
| --- | --- | --- |
| **键盘主控** | WCH CH585（RISC-V） | 支持原厂`beta1 0x3F`或官方0.64 `0x40`，按精确SHA独立适配，对应补丁协议 `V7.1`（能力值 `0x4350`） |
| **屏幕控制** | 雅特力 AT32F435（ARM Cortex-M4） | 支持原厂 `0x0002`，基础版 `UI 0.6.3 / L6`（能力值 `0x5536`） |
| **正常配置通信** | USB 本体（HID） | `VID 36B0 : PID 3075`，Usage `FF60:61`，Report ID 0，256 字节报文 |
| **主控升级模式** | USB IAP | `PID 3079`，64 字节报文，APP 起点 `0x2000`，镜像大小 `294912` 字节 |
| **屏幕升级模式** | USB IAP | `PID 3078`，64 字节报文，APP 起点 `0x4000`；基础版 `507904` 字节 / 歌词版 `540672` 字节 |
| **歌词扩展（可选）** | `L6 + LY1` | HELLO 应答 `0xA6 / 0x4C59`；**仅兼容已实读确认的 `1024KiB` Flash（系列 ID `0x0D`）AT32F435** |

> 仅支持与 [本地构建指南](build.md) 所列 SHA-256 一致的原厂固件版本。其他批次、不同屏幕型号或用同款主控的其他键盘都不直接通用，切勿强行改代码绕过校验刷写。仓库自带的 [vendor/Rainy75V2烧录工具20261112-1beta1.html](../vendor/Rainy75V2烧录工具20261112-1beta1.html) 已内嵌匹配这套校验值的 `0x3F` 主控和 `0x0002` 屏幕原厂固件（以及本项目不涉及修改的接收器 `0x26` 固件，详见 [vendor/README.md](../vendor/README.md)）。

## 有线 vs 无线模式的区别

很多人容易误会“键盘 2.4G 连着电脑能不能顺便校时或传歌词”，这里把两套路径分清楚：

- **键盘本地显示（可脱离电脑独立工作）**：
  只要提前刷好了主控和屏幕固件、传好了 S1 槽位的 GIF 动画、用 USB 校对过一次时间，平时切到 **2.4G 或蓝牙无线模式** 时，屏幕上的按键反馈、电量、模式图标、本地时钟走时和机器人动画都会正常更新。
- **PC 与屏幕交互（必须 USB 有线直连键盘本体）**：
  **刷固件、对时间、上传 GIF、上传 `FONT.BIN` 以及同步电脑歌词**，全都要走键盘本体 `36B0:3075` 的 USB HID 通道，公开工具尚未实现经2.4G接收器或蓝牙写屏；原生无线按键通知不等于PC无线歌词通道。

## 当前已知限制

1. **主控V7.1的验证范围**
   官方0.64基线已在单台开发设备完成刷写与校时读回，主控和屏幕时间一致、间隔两秒仍走时；这不能代替跨批次、完整休眠或断电保时验证。旧V7不应继续用于校时。
2. **完全断电后需重新校时**
   开发设备关电后RTC计数可能归零，旧锚点失效并显示横线。没有持续计时源就不能补回断电时间；其他批次的后备供电条件尚未核实。
3. **内部 RC 时钟存在温漂**
   默认按 `32000 Hz` 换算计时，受环境温度和个体芯片体质影响会有几秒的日常漂移；有实测数据的话可以通过 `AppClient.calibrate({ rate })` 在 `30000~40000` 范围内微调。
4. **按键显示的覆盖范围**
   屏幕直接消费键盘主控发出的原生最近一次按键通知（不追踪同时按下的完整组合状态），Fn 组合、改键层或非美式布局字符可能和系统最终输入字符不同；中文输入法正在打出的候选字也无法直接在小屏幕上显示。
5. **屏幕芯片与 Flash 空间差异**
   AT32F435 公开规格支持将 SRAM 配为 384KiB 或 512KiB，且外置素材 Flash 容量可能因生产批次而不同（目前已在一台开发机上实读确认 `1024KiB 片内 Flash + 4MiB 外置 Flash`，其中完整 `FONT.BIN` 占约 `2.4MiB`）。这也是为什么刷歌词版前网页会先强制查询片内容量，且上传字库时可能因原有 GIF/图片占满空间而需要手动清理。
6. **歌词扩展的实机进度**
   同源歌词代码在单台设备上实测过 QQ 音乐同步；目前公开版源码重新整理后以及网易云新版 Elog 进度读取部分，还缺足够多的实机回归测试（见 [验证说明](validation.md)）。

## 功能能力分层

[升级对照表](upgrade.md)区分基础版、四套传统歌词模板及第五套沉浸播放器。`alpha.4`是源码版本，LY1能力号本身不代表有封面或音量接口；后台查询模板数量与OP22字段12、21/22、23后启用支持的控件。音量也需要PC后台与USB，不是无线原生电量事件。
