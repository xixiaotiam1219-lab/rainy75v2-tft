# 兼容性与已知边界

本项目面向 Rainy75 V2 配套 TFT。主控为 CH585（RISC-V），屏幕主控为 AT32F435（ARM）；这两颗 MCU 的固件、地址和升级设备不同。

| 项目 | 当前约束 |
| --- | --- |
| 原厂主控 | beta1 `0x3F`，只接受构建文档所列 SHA |
| 原厂 IPS | `0x0002`，只接受构建文档所列 SHA |
| PC 配置入口 | USB 本体 `36B0:3075`，usage `FF60:61`，Report ID 0，256 字节 |
| 主控 IAP | `36B0:3079`，64 字节，APP `0x2000` |
| IPS IAP | `36B0:3078`，64 字节，APP `0x4000` |
| 新主控校时协议 | V7.1，能力值 `0x4350` |
| 新屏幕协议 | 0.6.2 / L6，能力值 `0x5536` |
| 接收器／蓝牙 PC 写屏 | 本工具不支持 |

无线模式下原生按键、状态通知和本地动画与 PC 写屏是不同路径。不能因为键盘可无线输入，就认为 PC 能经接收器上传素材、烧录或校时。不同批次、屏幕型号、同系列键盘或任意同芯片产品都不自动兼容。

## 当前已知限制

- 7.1 修正显式写入校时有效标记；它通过了开发阶段模型与网页校验，仍待实机校时确认。旧 V7 不应继续用于校时。
- 完全断电后主控计数可能归零，旧记录会失效；直接 USB 校时可重新建立映射，不能补回没有计时源支撑的断电时间。
- 内部 RC 会漂移。固件没有自动改动晶振或 RTC 源，也没有验证后备电池、VBAT 或外部晶振在所有硬件上的存在与接法。
- 原生通知用于显示最近按键，不实现按下／松开完整跟踪；Fn、特殊层、重映射键和不同布局仍需核实。
- 中文输入法最终文本、歌词、AI 额度、CPU 监控、后台服务和登录自启不属于当前版本功能。
- 模块通过固定地址与原厂 APP 协作。RAM 保留布局、更新时序和恢复能力都依赖指定版本；未做完整输入延迟、功耗、无线稳定性或寿命测量。

屏幕系列公开规格为默认 384KiB SRAM、可配置到 512KiB；具体设备的配置、空闲量和外部素材存储容量不能从固件大小推断。一帧 320×172 RGB565 为 110080 字节（107.5KiB），RAM 还需供原厂 GUI、解码、栈和其他状态使用。
