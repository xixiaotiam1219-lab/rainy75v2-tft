# 恢复与故障处理

恢复条件取决于实际硬件与 bootloader。没有经过验证的强制恢复入口时，原厂 BIN 的存在不能保证设备一定可恢复。

## 仍能枚举正常 USB 本体

先停止其他驱动与同步程序，确认使用的是 USB 本体。保留错误信息与构建清单，核对型号和版本。不要在未定位原因时重复校时、擦除或更换随机固件。

可按 [构建说明](build.md) 的 `--restore-stock` 生成本机原厂恢复 BIN 与清单，使用相同的目标选择与逐字节校验流程恢复应用。也可使用合法取得、适用于该设备的原厂烧录工具。

## 仍能枚举 IAP

在工作台核对恢复 BIN 和清单后，可直接点“选择升级设备”，无需再发送“进入升级模式”命令。必须选择对应的主控 `3079` 或 IPS `3078`，写入成功后检查键盘与屏幕实际状态。

工具不写 bootloader，也不提供任意地址读取、全 Flash 导出或实际设备备份功能。恢复文件只来自用户提供的原厂 APP，不含原设备特有配置的备份保证。

## 正常 APP 与 IAP 都不出现

本项目尚未为所有硬件确认独立 BOOT／RESET 或按键强制恢复步骤。不要照搬其他键盘或同芯片开发板的接线和组合键；应联系厂家获得准确恢复说明。必要时可能需要匹配电压、接线和访问权限的硬件调试器，由有经验的人处理。

请勿把“烧录校验通过”与“设备已能完整正常启动”合并为一个结论。恢复后分别核对输入、显示、连接模式和后续休眠行为。
