# 恢复与救砖指南

如果刷机过程意外中断、屏幕黑屏或者想退回原厂固件，按下面三种情况一步步排查，先别慌也不要拿来路不明的固件乱刷。

> 强烈建议在刷机前就已经按 [本地构建指南](build.md) 的 `--restore-stock` 生成过 `build/main-restore/` 和 `build/ips-restore/` 恢复包。它们是你提取的原厂 APP 加空余填充镜像，专门用来配合工作台刷回原厂状态。

---

## 情况一：电脑还能认出正常键盘（PID `0x3075`）

比如只是屏幕显示错乱、动画花屏，或者改坏了想退回原厂：

1. 关掉所有其他驱动网页和歌词后台，用 USB 数据线直连键盘并切到有线档。
2. 先不要急着反复重刷或乱改，记录下刚才报错的界面信息。
3. 打开本地工作台（<http://127.0.0.1:8765/web/>），在 **「04 / FIRMWARE」** 区域载入恢复目录下的 `rainy75v2-main-restore.bin` 或 `rainy75v2-ips-restore.bin` 与对应的 `manifest.json`。
4. 按正常升级步骤点「核对目标与 SHA-256」→「进入对应升级模式」→「选择升级设备」→「擦除应用区并烧录」，等待全字节校验完成即可恢复原厂程序。如果有官方原厂升级工具，也可以直接用官方工具重刷。

---

## 情况二：黑屏/按键无反应，但能看到 IAP 升级设备（PID `0x3079` 或 `0x3078`）

如果刚擦除完应用区就断电/断线了，或者新固件没跑起来，芯片通常会直接停在 Bootloader（IAP 模式）里等待重新写入。

1. 在工作台 **「04 / FIRMWARE」** 载入对应芯片的原厂恢复 BIN 和 `manifest.json`，点 **「核对目标与 SHA-256」**。
   - **特别注意核对目标**：主控升级设备是 `0x3079`，IPS 屏幕升级设备是 `0x3078`，一定别选反。
2. 此时键盘已经处于 IAP 模式了，**不需要点「进入对应升级模式」**，直接点击 **「选择升级设备」**，在浏览器弹窗里选中当前出现的升级设备。
3. 点击 **「擦除应用区并烧录」**，跑完写入与全字节校验后重启，再检查屏幕显示、按键输入、2.4G/蓝牙切换和休眠唤醒是否都恢复正常。

---

## 情况三：正常模式和 IAP 设备都枚举不出来了

如果插拔 USB 后既没有 `0x3075`，也没有 `0x3079`/`0x3078` 出现，说明问题已经超出了应用区固件的范围（可能是 Bootloader 异常、电源异常或硬件批次不兼容）：

- 仓库目前**没有针对所有生产批次整理出通用的短接引脚或组合键强进 Boot 方案**。
- **切勿直接套用其他型号键盘或芯片开发板的接线/短接按键方法**，电压或引脚定义对不上容易烧坏板子。
- 建议先联系 WOB 官方售后或社区获取对应批次的官方救砖方法；如果已明确掌握了芯片丝印与对应引脚定义，再请有经验的硬件玩家用匹配的调试器（如 WCH-Link / SWD）处理。

> 提醒：本工作台只会擦写应用区（APP），不会动 Bootloader，也不提供全片 Flash 备份读取功能；恢复包来自你本机提供的原厂镜像，恢复后记得去原厂驱动检查一下自己的按键/灯效设置还在不在。
