# 工作台交互与视觉约定

把它理解为普通键盘用户的本地设备工具：清楚的状态、可选定制、少量文字。使用 design-taste-frontend 的审查、排版、配色与可访问性规则；安装流程按设备状态组织，不套用营销页动效。

视觉变化 / 动效 / 密度为 **5 / 3 / 4**。中性底色，莓粉强调；明暗两种页面外观，独立于键盘主题。表面 16px、控件 8px、紧凑选项 6px 圆角。沿用原生 HTML、Canvas 和本地 CSS，发布包不加载 CDN。

## 改造前

- 五个标签把所有操作都画成必经步骤，三个模式卡实际有两种共用固件。
- 带棕色底、渐变与大量徽标的卡片层层嵌套，说明、参数和按钮抢同一层级。
- 字库、主控基线与手动 BIN 加载容易被误认为普通用户的准备工作。
- 默认预览素材可能被更新计划当成用户明确选择的 S1 素材。
- 升级后重新授权、停止后台失败、安装完成后应用播放器设置缺乏清楚衔接。

## 默认界面

首页只选择「桌宠与按键」或「再加一个播放器」，显示软件预览和连接按钮。全部模板演示、环境信息可展开。修改 GIF 与主题属于可选操作。

安装页显示连接结果、待写入内容的短摘要、安装按钮与进度。完整步骤、日志、硬件参数、手动文件和日常维护均可展开。一般解释由「帮助」按钮显示；校验失败和连接错误始终可见。

基础版不引入字体与后台。传统与沉浸播放器共用歌词固件，安装完成后可应用选定布局、字号与音量参数，再启动后台。

## 设备流程约束

- 正常模式、主控 IAP、屏幕 IAP 分开识别；每次换 PID 需要浏览器授权时停下来等待点击。
- APP 重连失败不在计时器中弹授权窗口，进入等待重连状态。
- 更新场景未明确选定 GIF 时保留 S1；默认预览、发布包含有素材均不算用户选择。
- 首次进入升级前核对整套所需文件；芯片容量缺失时在 APP 模式补读，不能删掉容量或地址校验。
- 写入、上传或校验期间不关闭 HID；仅在等待授权或已失败时提供结束操作。
- 「后台未响应」与「后台已停止」分开处理，不能把无应答当作 USB 已释放。
- 页面切换回到内容顶部；设备授权提示自动进入可见位置并聚焦操作按钮。

## 验证范围

主机测试与浏览器烟测使用合成固件、模拟 HID 和隔离的临时后台目录。明暗外观、390px 窄屏、键盘导航及完整授权流程在无头浏览器检查。它们不代表实际硬件刷写或无线验证。
