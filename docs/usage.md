# 使用方法

请先读 [免责声明](../DISCLAIMER.md) 与 [兼容性](compatibility.md)。当前是实验候选，主控 7.1 校时修正仍待实机确认。没有本地合法原厂文件或没有可接受的恢复条件时，可先使用离线预览与代码，不必烧录设备。

## 1. 准备

需要 Rainy75 V2 及配套 IPS 屏幕、可传数据的 USB 线、支持 WebHID 的桌面 Chrome / Edge，以及按 [构建文档](build.md) 生成的文件。2.4G 接收器、蓝牙连接不是本工具的 PC 写屏传输入口。

先在原厂驱动中把屏幕设为 GIF 播放、选择槽位 1，确认原画面正常。保留原厂工具与文件。关闭其他占用键盘的驱动、烧录和同步页面。

在项目目录运行：

```sh
python tools/serve.py
```

打开 <http://127.0.0.1:8765/web/>。本地服务只监听 `127.0.0.1`；退出终端或按 Ctrl+C 可关闭服务。不要用 `file://` 打开模块页面。

## 2. 首次升级

保持键盘电源开启，USB 连接并切到有线模式。建议先主控，再 IPS；已有相同版本 IPS 时无需反复重刷。

1. 在“烧录”区域选择同一次构建的 BIN 与 `manifest.json`，点“核对目标与 SHA-256”。
2. 核对页面显示的目标是“键盘主控”还是“IPS 屏幕”。
3. 点“进入对应升级模式”，选择 USB 键盘本体。
4. 等设备重新枚举后，再点“选择升级设备”。这一步需要新的点击以触发浏览器授权。
5. 点“擦除应用区并烧录”，等待写入与全部字节校验完成。过程中保持 USB 连接与供电。
6. 如果需要更新另一颗 MCU，选择它自己的 BIN 和清单，重复操作；不要用一个目标的文件替代另一个。

| 目标 | 升级设备 PID | 写入起点 |
| --- | --- | --- |
| 键盘主控 CH585 | `0x3079` | `0x2000` |
| IPS 屏幕 AT32F435 | `0x3078` | `0x4000` |

浏览器设备授权属于你选择的设备。本工具不自动进入升级模式或自动烧录。

**刚刷完主控、还没有校时，显示 `--:--:--` 是预期状态。** V7.1 在启动后接收当前时间，不依赖刷机前的计数器值。

## 3. 上传默认动画

重新连接 USB 键盘，点击“连接键盘”。在“更换缓存动画”选择以下任意文件：

- `assets/robot-pink.gif`
- `assets/robot-mint.gif`
- `assets/robot-mono.gif`

确认“替换 S1 槽位素材”后上传。它会覆盖该槽位现有素材，上传时原厂的 `Downloading` 界面可能出现一次。上传应答完成后，请实际查看屏幕；应答不是可见画面成功的替代证明。

素材配色应与 IPS 构建时的 `--theme` 对应；不同配色混用会让动态文字区域和背景有色差。日常动画从设备缓存播放，不需要打开网页反复发送 GIF。

## 4. 校时与日常使用

1. USB 有线连接，点击“连接键盘”。
2. 检查时区，默认跟随浏览器系统时区；北京时间可填写 `Asia/Shanghai`。
3. 点击“写入当前时间并核对”。完成提示需要主控与屏幕读回时间均通过核对。
4. 成功后可断开并关闭网页；动画、按键、电量与连接图标由键盘本地更新。

默认计时换算频率使用近似 `32000Hz`，不代表每块设备的精确校准。内部 RC 会随条件漂移；源码中的 `AppClient.calibrate({ rate })` 支持经实测得到的 30000–40000Hz 参数。没有可靠测量时不要按显示误差随意修改硬件时钟寄存器。

完全关电导致 RTC 计数重置时，旧记录会失效并显示横线。再次连接 USB，用同一校时按钮即可重校，不必重刷固件。当前仍不能保证关电后继续走时。

## 5. 检查显示

- 初次启动未收到按键：键帽显示 `--`。
- 按 A、Enter、方向键、PgUp / PgDn：查看对应图标；松开后保留最近一键。
- 左右 Win 共用居中的四格图标，ESC / CTRL / ALT 使用文字。
- Shift 与标点的映射按常见美式布局处理，不能当成输入法最终输出或任意自定义键盘布局的文字解析。
- 电量和连接模式需要收到原生状态通知；未知状态可显示空白或 `--`，不要把预览中的示例值当作实际值。

## 6. 遇到问题

| 现象 | 先做什么 |
| --- | --- |
| 找不到设备 | 确认 USB 数据线、有线模式、浏览器支持，关闭其他驱动页；接收器不是 USB 本体 |
| 旧版协议被拒绝 | 核对主控 V7.1、IPS L6 及原厂输入版本，不绕过版本检查 |
| 校时返回状态 7 / 写入校验失败 | 保持 USB，停止重复写入，记录版本和错误；此候选尚待实机确认 |
| 时间横线 | 先校时；若刚才完全关电，旧记录失效是预期保护；若未关电也发生，按实际切换／休眠步骤报告 |
| 动画和界面不匹配 | 确认槽位 1、GIF 模式、模板素材与固件配色一致 |
| 烧录中断或设备不能启动 | 按 [恢复说明](recovery.md) 判断是否仍可进入 IAP，不试未知命令或继续写错误目标 |

本页讲的是基础屏幕版：日常显示不需要 Windows 后台。可选歌词扩展另有后台与登录自启控制，按 [歌词版步骤](lyrics.md) 单独安装；不要把两个功能的构建目录、字库和使用要求混在一起。
