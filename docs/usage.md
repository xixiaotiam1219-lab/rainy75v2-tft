# 基础版使用指南（刷机、上传动画与校时）

这篇文档带你完成**基础屏幕版**的刷机、上传像素机器人动画、对准时间，以及上机检查。如果你还没编译出固件，请先看 [本地构建指南](build.md)。

> 如果你只用基础版（大单键、时钟、电量、模式图标、小机器人），按本页操作完就可以彻底关掉网页，**不需要装 Node.js，也不需要电脑开着后台**。歌词扩展请等基础版跑通后再看 [歌词扩展文档](lyrics.md)。

---

## 1. 动手前准备

1. **硬件连接**：用**能传数据的 USB 线**直接插上键盘，并把键盘切到**有线模式**（2.4G 接收器和蓝牙模式都不能刷机、传图或校时）。
2. **浏览器要求**：桌面版 **Chrome** 或 **Edge**（需要支持 WebHID）。
3. **关闭占用程序**：把 WOB 官方网页驱动、官方桌面驱动、`vendor/` 里的原厂烧录网页或任何其他串口/固件页面都关掉，否则 USB HID 接口会被占着连不上。
4. **原厂屏幕设定**：先在原厂驱动里确认屏幕当前处于 **「GIF 播放」模式，且选中的是「槽位 1（S1）」**，画面能正常动起来。
5. **启动本地工作台**：在仓库根目录运行：
   ```sh
   python tools/serve.py
   ```
   然后用浏览器打开 <http://127.0.0.1:8765/web/>。
   > 注意：一定要通过上面的本地地址打开，**不要直接双击 `web/index.html`（`file://` 协议）**，否则浏览器会拦截脚本加载和 WebHID 权限。操作完终端按 `Ctrl + C` 关闭即可。

## 2. 烧录主控与屏幕固件

在网页工作台拉到最下面的 **「04 / FIRMWARE（使用自己的构建产物）」** 区域。建议**先刷键盘主控，再刷 IPS 屏幕**（如果你之前已经刷过同版本普通 IPS，就不用再重复刷屏幕）。注意：这里用的是 `web/` 工作台去刷你自己编译的 `build/` 固件；如果想刷回出厂原版（或刷接收器 `0x26`），请用 [vendor/](../vendor/README.md) 里的原厂烧录 HTML。

### 烧录步骤（主控与屏幕流程相同，只是选的文件不同）

1. **选文件并校验**：分别点「固件 BIN」和「构建清单」，选中**同一次编译出来的**文件（比如 `build/main/rainy75v2-main.bin` 和 `build/main/manifest.json`），点 **「核对目标与 SHA-256」**。页面会显示这次要刷的是「键盘主控」还是「IPS 屏幕」。
2. **进入升级模式**：点 **「进入对应升级模式」**，浏览器弹窗里选中当前的 USB 键盘（`36B0:3075`）授权连接。键盘会自动重启并切进 Bootloader（IAP 模式）。
3. **第二次选设备（重点！）**：等大约 1～2 秒让电脑重新识别新设备后，再点 **「选择升级设备」**。
   > **为什么要点两次选择设备？**
   > 键盘正常工作时的 USB PID 是 `0x3075`，进入升级模式后会变成另一颗 Bootloader 设备（主控是 `0x3079`，屏幕是 `0x3078`）。浏览器的 WebHID 安全限制要求换了 PID 必须由你手动重新点一次授权，这不是出错或卡死。
4. **开始擦除并写入**：点 **「擦除应用区并烧录」**，耐心等进度条跑完擦除、写入和全字节校验。**期间千万不要拔线或关开关**。
5. **烧录另一颗芯片**：主控刷完重启回正常键盘后，再选 `build/ips/` 下的 `rainy75v2-ips.bin` 和 `manifest.json`，把第 1～4 步重走一遍。**千万注意不要把两个目标的文件选混！**

| 目标芯片 | 升级设备 PID | 应用区起始地址 |
| --- | --- | --- |
| 键盘主控（CH585） | `0x3079` | `0x2000` |
| IPS 屏幕（AT32F435） | `0x3078` | `0x4000` |

**提醒**：刚刷完主控还没校过时的时候，屏幕时间显示 `--:--:--` 是完全正常的，继续往下走第三、四步就好。

## 3. 上传小机器人动画到 S1 槽位

为什么一定要传 GIF？因为屏幕的动态文字和键帽边框是直接叠画在 S1 槽位的背景 GIF 上的。如果 S1 里还是原厂图或者别的配色，画出来的字框颜色就跟背景对不上。

1. 刷完固件等键盘重新亮屏连上电脑后，在工作台 **「02 / DEVICE」** 区域点 **「连接键盘」**。
2. 在右侧 **「更换缓存动画」** 选择与你刚才编译 IPS `--theme` 对应的 GIF（可以在 `assets/` 或 `build/ips/assets/` 里找）：
   - 樱花粉：`robot-pink.gif`
   - 薄荷绿：`robot-mint.gif`
   - 墨水灰：`robot-mono.gif`
3. 勾选 **「确认替换 S1 槽位素材」**，点 **「上传 GIF 到 S1」**。
4. 传图过程中屏幕弹出一次原厂的 `Downloading` 界面属于正常现象。提示上传完成后，直接低头看一眼键盘屏幕，确认机器人动画正常动起来且底色协调即可。

传好后 GIF 就存在屏幕 Flash 里了，日常使用不需要开网页一直传。

### 已安装旧示例机器人，出现闪烁时

旧公开示例的 GIF 使用了每帧恢复背景的 `disposal=2`；本次更新改为保留上一帧的 `disposal=1`，同时保持每帧完整覆盖。遇到按键时机器人和边框一起短暂消失，先按下面步骤替换素材：

1. 从最新仓库的 [`assets/`](../assets/) 下载与你当前固件同主题的 `robot-pink.gif`、`robot-mint.gif` 或 `robot-mono.gif`。可以直接下载文件，无需重新构建；不要使用旧 `build/` 里缓存的 GIF。
2. 退出歌词后台，关闭其他驱动，用 USB 有线连接；按上面的工作台步骤，把新 GIF 上传到 **S1** 并确认覆盖。
3. 上传完成后连续按 `W/A/S/D`，再松开观察动画。使用歌词扩展的用户再切到歌词页、切回按键页检查恢复，然后重新启动后台。

这次只更新动画文件，无需重刷主控或 IPS、重传 `FONT.BIN` 或重新校时。公开修正素材已通过离线帧检查；受影响设备仍需按第 3 步确认实际显示，若还闪烁请反馈使用的主题及是否仅在按键时发生。

## 4. 对准时间与日常使用

1. 保持 USB 连接，在工作台 **「将时间同步到电脑」** 栏核对时区（默认会跟随浏览器系统时区，北京时间就是 `Asia/Shanghai`）。
2. 点 **「写入当前时间并核对」**。网页会自动把当前秒数写入主控 `0x49000` 校时页，并同时读回主控和屏幕的时间确认两边已经对上。
3. 看到提示「校时通过，可以关闭网页」后，就可以直接关掉浏览器、拔掉线切去 2.4G 或蓝牙正常用了。

### 关于走时精度和断电重置

- **走时会有小幅飘移**：CH585 内部 RC 振荡器默认按 `32000 Hz` 换算，芯片受温度影响每天可能有几秒误差。如果你实测了自己的晶振/RC 偏差，源码里的 `AppClient.calibrate({ rate })` 支持手动传入 `30000~40000` 之间的频率参数来修正。
- **彻底关开关后时间变 `--:--:--`**：该开发设备完全断电后RTC计数可能归零；其他批次供电布局未核实。重新开机后主控会自动检测到计数回退并让旧校时失效（显示 `--:--:--`），防止给你看一个假时间。遇到这种情况不用重刷固件，插一次 USB 点一下校时按钮就恢复了。

## 5. 上机验收清单

刷完校好时间后，建议按下面几项顺手测一下：

- **初始状态**：刚通电还没按任何键时，左边大键帽框显示 `--`。
- **按键反馈**：按 `A`、回车、方向键、`PgUp` / `PgDn`，对应大图标正常显示且松开后保留；按左右 `Win` 都会显示居中的四格图标；`ESC`、`CTRL`、`ALT` 显示对应英文。
- **Shift 符号**：按住 Shift 再按数字或标点，会按标准美式键盘映射显示上档符号（如 `!@#$%`）。
- **状态栏**：拔掉 USB 切到 2.4G 或蓝牙，检查右上角连接图标和电池电量百分比是否跟着变化（刚开机主控还没推送过状态前可能会暂时显示空白或 `--`）。

## 6. 常见报错与排查

| 遇到什么问题 | 怎么处理 |
| --- | --- |
| **点连接找不到设备** | 1. 确认用 USB 数据线直连键盘（不要选成 2.4G 接收器）；<br>2. 键盘拨到有线档；<br>3. 关掉 WOB 官方网页驱动或其他开着的串口/HID 工具；<br>4. 换 Chrome 或 Edge 桌面版。 |
| **提示不是支持的 V7.1 / L6** | 说明你设备里还是旧版固件或版本不对。去 [本地构建指南](build.md) 确认原厂输入 SHA，重新编一份并完整烧录。 |
| **校时报错（状态 7 或读回失败）** | 不要反复狂点写入。保持 USB 连接，先在工作台点「读取状态」看看当前主控和屏幕返回什么；官方0.64基线已有单台设备校时读回，但完整休眠/断电保时仍未解决，遇到稳定复现欢迎带读数提 Issue。 |
| **屏幕时间突然变成 `--:--:--`** | 先回忆刚才是不是拨过总电源开关。断电重来变横线是正常保护，直接连 USB 点一次校时就行。如果没断电只是睡了一觉就掉时间，记录好操作步骤反馈 Issue。 |
| **动画和边框有色差** | 检查原厂驱动是否设在「GIF 播放 · 槽位 1」，再确认你上传的 `robot-*.gif` 配色和编译 IPS 时传的 `--theme` 一致。 |
| **旧示例机器人和边框一起闪烁** | 下载最新同主题 GIF 并覆盖 S1，见上面的「已安装旧示例机器人，出现闪烁时」；不需要重刷固件或字库。 |
| **烧录中途断开或黑屏不开机** | 先别乱刷别的文件，直接去看 [恢复与救砖指南](recovery.md) 判断能不能进 IAP 刷回原厂恢复包。 |

## 从旧版本升级

原生电量、连接图标和按键页不依赖新增沉浸播放器或音量后台。需要哪些功能、是否重刷IPS、是否复用字库，按 [升级对照表](upgrade.md)选择。官方0.64与旧0x3F主控要使用各自精确SHA对应的构建，不能混用地址。
