# 歌词播放器扩展安装与使用

这是一个加在**基础屏幕版**上面的可选功能。如果你只需要大单键、时钟、电量和机器人，看 [基础版使用指南](usage.md) 就够了，不用装这部分。

打开歌词页后，小屏幕会变成「留白电台」全宽布局：顶部保留时钟/连接/电量，中间不画机器人以腾出完整宽度，默认显示 **20px 歌名 + 40px 大字当前句**，也可在控制台一键切回 **20px 双行歌词**（同时显示当前句和下一句），底部带播放进度条。传统四模板保留该布局；另有沉浸封面模板，隐藏顶栏。**Ctrl+F8**循环按键页与五套播放器，旧固件按能力减少可选项。

---

## 先确认前置条件

1. **系统与连接限制**：PC 歌词同步后台目前**只支持 Windows + USB 有线模式**（公开后台尚未实现2.4G或蓝牙歌词同步）。如果只是想在 macOS/Linux 上离线看看控制台界面，可以跑 `npm run lyrics:demo`。
2. **芯片容量硬要求**：歌词代码装在屏幕的 Bank2 区域，**只支持片内 Flash 为 `1024KiB` 的 AT32F435（系列 ID `0x0D`）**。刷机前网页工作台会自动先向屏幕发起只读查询，确认芯片符合条件才会让你进入升级。
3. **必须先装本仓库新版普通 IPS**：就算你的屏幕以前刷过老版 `L6`，也要先编译并刷入当前版本的普通 IPS（UI `0.6.3 / L6`）和主控 `V7.1`，因为老版不带上面说的芯片容量查询接口。同时记得用 `--restore-stock` 留好恢复包。

## 第一步：在本地生成点阵字库 `FONT.BIN`

为了让切歌、换句不卡顿也不反复弹 `Downloading`，本方案把 20px 点阵字库提前一次性存进屏幕外置 Flash，平时后台只发字形编号。**20px、40px及沉浸页30px共用这一份字库**（40px 在屏幕内按 2×2 像素整数放大绘制，既省空间又保留清晰像素感）。

1. 前往 [Noto CJK 仓库](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese) 下载 `NotoSansCJKsc-Regular.otf`，放进本地 `inputs/` 目录。需要匹配以下 SHA-256：
   ```text
   2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b
   ```
2. 确保装好了开发依赖（`pip install -r requirements-dev.txt`，里面包含了 Pillow 和 fontTools），运行生成脚本：
   ```sh
   python tools/fontpack.py --source inputs/NotoSansCJKsc-Regular.otf
   ```

跑完后会在 `build/font/` 生成 `FONT.BIN`（约 2.4 MiB，包含源字体覆盖的简体中文、繁体中文、日文假名汉字与拉丁字符共约 44,810 个码点）、预览图 `font20-preview.png` 以及对应的 `OFL-1.1.txt` / `FONT-NOTICE.txt` 版权文件。遇到字库里没有的生僻符号或 Emoji 时会回退显示成方框 `□`。

## 第二步：编译并刷入歌词版 IPS

用刚才生成的字库来编译歌词扩展版屏幕固件（`--theme` 依然支持 `pink` / `mint` / `mono`）：

```sh
python tools/build.py ips --stock inputs/ips-stock.bin --lyrics --font build/font/FONT.BIN --theme pink
```

输出全部在独立目录 `build/ips-lyrics/` 下（有 `rainy75v2-ips.bin`、`manifest.json`、同一次绑定的 `FONT.BIN` 和同主题 GIF），不会覆盖 `build/ips/`。

**刷入流程**：
1. 退出其他桌面端后台和 WOB 官方驱动，运行 `python tools/serve.py`，浏览器打开 <http://127.0.0.1:8765/web/>。
2. 在 **「04 / FIRMWARE」** 选中 `build/ips-lyrics/` 里的 `rainy75v2-ips.bin` 和 `manifest.json`，点 **「核对目标与 SHA-256」**。
3. 点 **「进入对应升级模式」**：网页会先自动连上当前键盘查一下芯片是不是 `1024KiB / 系列 0x0D`。查通过后才切进 IPS IAP；如果提示不支持或缺少查询接口，**先回普通模式刷入新版普通 IPS**。
4. 点 **「选择升级设备」**（选 `0x3078`）并点击 **「擦除应用区并烧录」** 完成全字节校验。

> 内存与地址边界供参考：歌词代码段在 `0x08080000..0x08088000`，整包大小 `540672` 字节，已实测过的 Bootloader 擦除范围到 `0x080C0000`，不会覆盖高地址处（`0x080FC000` 等）的原厂键盘设置。

## 第三步：一次性上传主题 GIF 和 `FONT.BIN`

刷完重新连上键盘，先别急着开歌词后台，留在工作台网页里把文件传进屏幕：

1. 在 **「02 / DEVICE」** 点 **「连接键盘」**，把 `build/ips-lyrics/assets/robot-<theme>.gif` 上传到 S1 槽位。
2. 在 **「03 / OPTIONAL LYRICS」** 选中 **同一次构建目录下** 的 `build/ips-lyrics/FONT.BIN`（首次安装**不要勾选**「替换已有字库」），勾选确认写入后点 **「上传字库」**。
   > **提示**：屏幕会弹出一次`Downloading`，所需时间随设备和传输环境变化。传完之后就一直留在屏幕里了，只要以后不重新编字库就不用再传。如果首次安装提示空间不足，先打开 WOB 官方驱动把不需要的多余图片/动画删掉腾地方。
   >
   > 另外，固件编译时会把 `FONT.BIN` 的 CRC 写死在程序里，如果上传时提示“字库与屏幕固件不匹配”，说明你选成了不同批次构建的文件，重新拿 `build/ips-lyrics/` 下那套配套的来传即可。

### 更换已有字库

如果你以后升级了新版字库（或者自己改过字体），直接重传一次 `FONT.BIN` 往往会报“空间不足”，因为原厂文件系统计算可用空间时未必会把同名旧文件先释放掉。此时请按下面两步走安全替换流程：

1. **留好旧文件并刷入新固件**：手头留一份屏幕里当前正在用的旧 `FONT.BIN`、旧固件和恢复清单；退出歌词后台后，先为新字库编好并刷入对应的**新版歌词固件**（刚刷完时新固件暂时打不开旧字库，属于正常的中间状态）。
2. **在工作台执行替换**：在 **「03 / OPTIONAL LYRICS」** 选好新 `FONT.BIN`，勾选 **「替换已有字库（首次安装不勾选）」**，接着选择屏幕里对应的 **旧 `FONT.BIN`**，勾选确认后点 **「上传字库」**。
3. **后台自动处理顺序**：工作台会先核对本地新旧两份字库及新固件期望的 CRC；随后暂停屏幕绘图并通知设备核对屏幕内 `FONT.BIN` 的文件头、大小和 CRC，校验无误后**只删除 `FONT.BIN` 这一个文件**，紧接着上传新字库。

> **注意事项**：替换过程在“旧字库删完、新字库写完”之间存在短暂的空白窗口，**不是断电原子操作**。如果传到一半断线了，保持 USB 连接修好环境后，按“首次安装”流程不勾选替换直接把新 `FONT.BIN` 重传一遍即可；如果要刷回旧固件，记得也换回对应的旧 `FONT.BIN`。另外，该接口不会触碰 S1–S4 的任何动画素材，也不会格式化存储。

### 独立删除字库

1. 退出歌词后台，保持 USB 有线连接；在工作台的「歌词播放器扩展」中，选择与屏内当前版本一致的旧 `FONT.BIN`。
2. 点击「仅删除屏内字库」，阅读确认框并确认。无需选择新字库，也不会开始新文件上传。
3. 工具验证本地旧文件，暂停屏幕合成，等待 GUI worker 核对旧头部和大小并仅移除固定 `FONT.BIN`，然后恢复。接口不接受任意文件名。
4. 删除后保留原 GIF 与基础按键页。歌词同步需要字库，请保持后台关闭；想恢复时上传与当前固件匹配的字库后再启动。

缺少删除接口、旧文件不匹配或维护失败时停止，不尝试删除其他素材。不提供屏内字库导出功能，因此更换或删除前需要自行保留当前文件。编程接口：`await client.deleteFont(currentFontBytes, {deleteConfirmed: true})`。

## 第四步：启动 Windows 歌词后台

安装好 **Node.js 22+**，在仓库根目录安装依赖并启动后台：

```sh
npm install
npm run lyrics
```

终端会输出一个本机控制台地址，比如 `http://127.0.0.1:xxxxx`，按住 Ctrl 点击在浏览器打开就是 **「留白电台」** 控制页（如果后台已经在跑，重复执行 `npm run lyrics` 会直接把已有地址打印给你）。日常使用时后台静默挂着就行，**网页控制台可以随时关掉**。

想在没有键盘或非 Windows 电脑上先看看控制台长啥样，可以跑离线演示模式：

```sh
npm run lyrics:demo
```

演示模式只展示内置示例歌词，不会连接 USB、不会注册全局热键、也不会读取你电脑上的播放器。

> **环境变量（进阶）**：如果把 `FONT.BIN` 或后台数据放到别的位置，启动前可以设置 `RAINY75_FONT`（字体文件路径）和 `RAINY75_DATA`（设置和日志目录，默认 `local/lyrics/`）。

## 第五步：控制台功能与播放器支持

在「留白电台」页面里可以操作以下功能：

- **切换页面 / `Ctrl + F8`**：键盘随时按 `Ctrl + F8`（或在网页点按钮）依次循环按键页→原版双行→04大字字幕→大字聚焦→双行大字→沉浸封面。快捷键只监听这一个组合，若被其他软件占用会在页面给出提示。
- **传统歌词模板**：默认「04大字字幕」（20px歌名＋40px当前句），另有原版20px双行、大字聚焦、双行大字，共四套。切换只发送布局参数并自动保存，不重刷或重传字库；旧固件按实际支持的模板数量启用按钮。
- **歌词同步偏移**：支持 `-10.0 秒 ~ +10.0 秒`（`0.1 秒` 步进，附带提前/延后 `0.5 秒` 快捷按钮和归零）。**正值让歌词提前显示，负值让歌词延后**，不会改动播放器真实的播放进度；每次调整自动保存。
- **重新匹配歌词**：如果自动搜到了错误的歌词版本，点一下会重新按“歌名 + 歌手 + 专辑 + Live/Remix 版本标记 + 时长”匹配一遍（优先同平台，找不到再按更严苛的时长校验跨平台搜）。
- **导入本地 LRC**：临时把自己的 `.lrc` 文件拖/选进来给当前这首歌用（缓存在当前后台进程里，重启后台后需要重导）。
- **登录自启**：点「启用登录自启」会在当前用户的 Windows 启动文件夹写入一个静默启动脚本 `Rainy75V2-TFT-Lyrics.vbs`；不想要了点「取消登录自启」就会删掉。如果你移动了仓库目录或者升级挪动了 Node 安装路径，记得先取消再重新启用一次。
- **退出后台**：想回工作台网页校时、换 GIF 或重刷固件前，**一定先在这里点「退出后台」**，把 USB HID 接口释放出来。

### 沉浸封面与系统音量

第五套「沉浸封面」使用48×48小封面、随封面取色的雾面渐变和居中歌词，按用户选择隐藏时间、电量与连接顶栏；其他模板保留原状态栏。后台从Windows当前媒体会话读取封面，量化成64色后约1856B临时传输，仅更新RAM，不写素材Flash。切歌仍需传输小图，耗时随设备与负载变化；不能保证固定帧率或每次相同耗时。媒体没有封面时使用默认背景。

「沉浸页歌词字体」可实时选20/30/40px，默认30px清晰；柔和选项仅用于30px。设置保存到本机，不重传字库。

「系统音量提示」默认开启、仅在沉浸页显示、中央提示、停留1秒。可选进度区、所有页面和0.6–3秒；最后一次变化后计时，结束淡出。中央提示短暂遮住歌词，歌词同步继续。所有页面模式下，普通歌词页显示中央提示，按键页使用大键帽区域，结束恢复最近按键。

音量来自Windows默认播放设备的CoreAudio通知，包括静音；初始读取和重连不弹提示。不监听音量键或全局按键，也不修改系统音量。控制台「预览提示」仅把当前真实值发送给屏幕。每次状态payload仅6B，屏幕本地生成动画，不使用GIF或文件上传。后台与支持OP30的新歌词固件都需要更新，现有字库、主控和动画不因音量功能而更换。旧固件禁用相关控件；音量读取失败不停止歌词同步。

切页请求优先于文字、进度、封面和音量任务。alpha.5还允许在漏应答的显示等待期间取消旧任务，避免连续Ctrl+F8被8秒超时挡住。已排队的字形生成先完成再重传新内容；回到按键页不继续准备新歌词。只需退出旧后台、更新并重启，无需重刷已有兼容固件或字库。只更新磁盘上的脚本而不退出旧进程，不会让运行中的后台自动加载新代码。

如自行改用Windows计划任务登录自启，应使用普通进程优先级（Task Scheduler Priority 6），不使用低于正常或实时优先级。公开默认启动文件夹方案与自定义计划任务是不同入口，更新后确认只有一个后台运行。


已有用户先看 [升级对照表](upgrade.md)，按需选择A基础版、B传统歌词或C沉浸/音量增强。新增功能由能力查询启用，不要求传统播放器用户切换外观。

### 关于 QQ 音乐与网易云音乐

- **QQ 音乐**：直接通过 Windows 系统媒体会话（SMTC）获取歌名、歌手、时长和实时播放时间轴，同源逻辑（含 20/40 布局和字库替换）已经在开发机上做过实机验证。
- **网易云音乐**：新版网易云有时不会把实时进度汇报给 Windows SMTC，此时后台会只读网易云本机 `Elog` 日志里的当前播放事件来推算进度条（这部分代码已经过详尽的离线测试，**但在最新网易云客户端上的实机表现仍待进一步复核**）。后台不会保存或上传你的听歌历史和账号信息。

## 常见问题排查

| 现象 | 排查思路 |
| --- | --- |
| **一直显示「暂无可用歌词」** | 先看控制台里显示的歌词来源和匹配歌名/时长；可能是纯音乐、冷门曲库缺失，或遇到接口临时限流（后台会自动退避重试）。点「重新匹配歌词」或直接导入本地 `.lrc` 最快。 |
| **歌词跟歌对不上 / 错版** | 先看控制台显示的歌手和时长，排除把原版匹配成了 Live / Remix / 翻唱版；确认版本没错只是固定快慢半拍时，再用 ±10 秒偏移微调。 |
| **一直卡在「等待播放器进度」** | 检查播放器是否处于真正播放状态，或网易云/QQ 音乐版本有没有开启系统媒体控制/正常写入本地播放状态（项目不会从 0 秒盲目假装走进度）。 |
| **字库初始化失败 / CRC 不一致** | 检查三处是否来自**同一次构建**：刷进屏幕的固件、屏幕 Flash 里的 `FONT.BIN`，以及电脑端后台读取的 `FONT.BIN`（默认 `build/ips-lyrics/FONT.BIN`）。 |
| **替换字库报错旧文件不匹配** | 确认选择的旧 `FONT.BIN` 确实是屏幕里正在用的那一版，且已先退出歌词后台；老版不带 `OP 27` 的固件需先刷入新版歌词固件。 |
| **后台一直提示「等待 USB 键盘」** | 确认键盘在 USB 有线模式、已退出 WOB 官方驱动页面，且没有同时开着另一个控制台/烧录网页抢占 HID。 |
| **机器人和边框闪烁，或切回按键页时异常** | 旧公开示例也可能受影响：先下载最新同主题 `robot-*.gif` 覆盖 S1，见 [已有用户处理步骤](usage.md#已安装旧示例机器人出现闪烁时)。自定义 GIF 须为不透明完整帧、`disposal=1`，且 `(22,39)` 不与主题背景同色，见 [定制指南](customization.md)。 |
