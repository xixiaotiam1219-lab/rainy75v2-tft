# 歌词播放器扩展

这是在原有「基础屏幕版」之上可选安装的功能。只要按键、时钟、电量和机器人动画，请按 [基础版使用方法](usage.md) 操作，无需字库、Node 后台或歌词固件。

## 两个功能的区别

| | 基础屏幕版（原功能） | 歌词播放器扩展（新功能） |
| --- | --- | --- |
| 屏幕内容 | 原生大单键、时钟、电量、连接图标、缓存动画 | 保留按键页，增加全宽歌名、滚动歌词、播放进度 |
| 日常电脑后台 | 不需要 | Windows 后台持续运行；网页可关闭 |
| 日常连接 | 原生事件支持有线 / 2.4G / 蓝牙，依设备行为 | PC 歌词同步仅支持 USB 有线 |
| 屏幕固件 | 普通 IPS，输出 `build/ips/` | 可选 Bank2 扩展，输出 `build/ips-lyrics/` |
| 额外资产 | 一份原创机器人 GIF | 同主题 GIF + 一次性安装 `FONT.BIN` |
| 切换方式 | 本地按键界面 | 全局 Ctrl＋F8 或本机控制台 |

歌词页无角色，文字占满可用宽度；切回按键页仍有默认原创机器人。仓库不含私人角色、在线歌词缓存或原厂完整固件。

## 兼容性与验证

- 仍只接受 [构建文档](build.md) 中固定 SHA 的原厂输入。
- 歌词版只针对 **AT32F435 / 系列 ID `0x0D` / 片内 Flash 1024KiB**。并非每块同系列屏幕都兼容。
- 已在一台开发设备实测外置素材 Flash 4MiB；完整 20px 字库约 2.4MiB，不代表所有设备同容量或都有足够剩余空间。
- QQ 音乐的同平台歌词获取与后台提交已在开发设备验证。网易云进度重建有模拟测试，目前新适配尚待实机复核。
- 公开机器人与各主题由源码重新生成并做模型检查；单台私人配置的使用记录不能替代每份定制构建的实机确认。
- 歌词接口可能变化、限流或缺少某首歌；版本与时长校验降低误配风险，不能保证每首歌有正确歌词。

## 1. 先准备基础固件和恢复文件

按 [基础安装](usage.md) 准备 USB、有线模式、匹配原厂输入、主控 V7.1 和普通 IPS。**已有旧版 L6 的用户也要先构建并安装本版普通 IPS**，以增加只读芯片查询；L6 能力号不代表一定有这些查询。

保留同一原厂输入生成的恢复 BIN 和清单。字库生成、离线预览与后台演示均不自动连接或烧录设备。

## 2. 本地生成字库

安装 [构建依赖](build.md)。自行从 [Noto CJK](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese) 取得 `NotoSansCJKsc-Regular.otf` 放到 `inputs/`，需匹配下列源文件 SHA：

```text
2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b
```

```sh
python tools/fontpack.py --source inputs/NotoSansCJKsc-Regular.otf
```

生成 `build/font/FONT.BIN`、清单、预览和 OFL 版权说明。输入和生成字库均留在本机，仓库不打包字体源文件。字体含源字体所覆盖的简中、繁中、日语、拉丁文字；约 44810 个码点，不等于完整 Unicode。未知字符显示方框；无复杂排版引擎。

字库及其衍生部分适用 [SIL OFL-1.1](../licenses/OFL-1.1.txt)，不能因为项目代码是 MIT 就把字库重新标成 MIT。自定义字库应同步修改生成器、固件配置与主机索引，并保留相应许可。

## 3. 构建并安装歌词固件

```sh
python tools/build.py ips --stock inputs/ips-stock.bin --lyrics --font build/font/FONT.BIN --theme pink
```

需要时加 `--clang "/path/to/clang"`。输出为 `build/ips-lyrics/rainy75v2-ips.bin`、`manifest.json`、对应 `FONT.BIN` 和原创 GIF。普通 IPS 的产物仍保留在独立目录；不要混用两版清单。

关闭其他驱动与同步后台，打开 `python tools/serve.py` 的工作台。在烧录区选择歌词 BIN 与清单，再点「进入对应升级模式」。工具先通过本版普通 IPS 只读查询芯片容量和系列，只有 1024KiB / `0x0D` 才继续进入 IPS IAP。之后选择升级设备并完成全字节校验。

如果提示缺少查询，不绕过检查：回到 APP 模式，先安装本版普通 IPS。若已经停在 IAP，只能先用常规恢复文件恢复；歌词版不允许跳过 APP 硬件核对直接扩展写入。

本扩展代码区为 `0x08080000..0x08088000`，固定模块状态为 `0x2005F000..0x20060000`。支持设备的已读回 bootloader 擦除 APP 至 `0x080C0000`，原设置位于更高地址。这是特定版本的兼容依据，不是对其他批次 bootloader 的保证。

## 4. 一次性上传素材与字库

1. 重新连接 USB。使用歌词构建目录中的同主题 `assets/robot-<theme>.gif`，确认覆盖 S1 后上传。
2. 在「歌词播放器扩展」选择 **同一次构建的** `FONT.BIN`，确认写入并上传。
3. 正常文件上传可能显示一次 `Downloading`。完成后实际查看屏幕；以后正常换句只传字形编号和计时数据，不反复上传 GIF。

字库固定文件名 `FONT.BIN`，不覆盖 S1 GIF。空间不足时先用原厂工具管理多余素材；文件列表大小之和不代表文件系统实际可用空间。不要在字库上传期间运行同步后台。

固件、电脑和屏内字库的 CRC 必须一致。不一致会停止同步，重新选择同一次构建的文件，不能删除校验来绕过。

## 5. 启动 Windows 后台

安装 Node.js 22+，在仓库根目录运行：

```sh
npm install
npm run lyrics
```

终端会输出 `http://127.0.0.1:端口`，打开即为控制台。重复启动会返回已有后台地址。默认读取 `build/ips-lyrics/FONT.BIN`；后台数据保存在被 Git 忽略的 `local/lyrics/`。

不连接硬件也可以先看控制台：

```sh
npm run lyrics:demo
```

演示只用原创示例文字，不注册快捷键、不读取播放器、不连接 HID、不访问歌词网站。演示值不代表设备读数。

自定义字体或数据路径可在启动前设置 `RAINY75_FONT`、`RAINY75_DATA` 环境变量。更换字体后必须使用对应固件与屏内文件。后台只支持 Windows；基础网页和离线素材生成不依赖 Windows 后台。

## 6. 控制台与日常使用

- **Ctrl＋F8**：全局切换按键页 / 歌词页；只注册这个快捷键，不监听或记录全局按键。被其他程序占用时在控制台显示错误，可用界面按钮切换。
- **歌词偏移**：±10 秒、0.1 秒步长，含 ±0.5 秒和恢复默认。正值提前、负值延后；只影响歌词，不改歌曲实际进度，设置自动保存在本机。
- **重新匹配歌词**：重新查询当前曲目。同平台优先，匹配标题、歌手、版本、专辑与时长；首个重复候选没歌词时继续尝试，跨平台回退要求版本及时长可信。
- **本地 LRC**：为当前曲目导入自己的时间戳歌词，保存在当前后台进程的缓存中，退出后需要重新导入。
- **登录自启**：点击启用后创建当前用户的隐藏启动项；取消按钮移除该项。移动仓库或 Node 路径后应重新设置。
- **退出后台**：释放 USB 与快捷键。进行网页校时、上传或烧录前先退出后台，避免两个程序抢同一个 HID。

日常歌词同步要保留后台，控制网页可以关闭。未授权时不控制播放器播放、暂停、跳转或音量。QQ 需向 Windows 媒体会话提供曲目信息和进度；网易云在媒体时间轴不可用时只读本机 Elog 的当前播放事件重建位置。可读取的上游接口随客户端版本而变化。

长歌名在 286px 窗口独立滚动，最多 96 个码点，超过协议上限仍会截断。长歌词按时间拆成连续段并横向滚动；换句有纵向过渡。屏幕复用已缓存的标题与下一句，每个 GUI 周期最多处理四个字形读取；不在按键或 UART 回调做文件 I/O。

## 7. 排查歌词问题

| 现象 | 检查顺序 |
| --- | --- |
| 暂无歌词 | 看控制台来源、曲目版本与时长；等待退避重试或点重新匹配，再考虑导入本地 LRC |
| 歌词对不上 | 先排除 Live / Remix / 翻唱 / 剪辑版误配，再看媒体进度；固定小偏差才使用提前 / 延后 |
| 等待播放器进度 | 检查播放器是否向系统媒体会话提供时间轴；不要从零开始随意计时假装同步 |
| 字库初始化或 CRC 错误 | 核对固件、电脑 FONT.BIN 与屏内文件来自同一次构建 |
| 控制台找不到 USB | 有线模式、只有一把匹配设备，退出原厂驱动和其他后台 |
| 原动画交替闪 | 使用本项目生成的完整帧 GIF；自定义 GIF 必须满足每帧完整恢复与标记像素条件 |

后台会读取当前曲目元数据，并向 QQ / 网易云公开接口发送标题、歌手等检索条件。Elog 适配只保留当前曲目、位置和播放状态，不保存原日志、账户数据或播放历史。不在问题报告中上传个人媒体日志。

开发验证与证据范围见 [验证文档](validation.md)，定制提示词见 [AI 协作指南](ai-guide.md)。
