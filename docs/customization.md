# 定制图标、配色与动画

工作台网页里自带的像素编辑器可以让你直接点格子画大图标并预览效果。不过要注意：**网页里导出的是配置 JSON，想让键盘屏幕真正变样，必须把导出文件喂给 `tools/build.py` 重新编译 IPS 固件并刷入（换配色的话还要配套上传对应的 GIF）**。

---

## 1. 修改大按键图标（`profiles/keys.json`）

最省事的方法是在工作台网页的「01 / DESIGN」里选好键位，鼠标点格子改好后点 **「导出图标配置」** 保存成 `keys.json`；当然你也可以直接用文本编辑器改 `profiles/keys.json`。

每个图标条目格式如下：

```json
{
  "key": 227,
  "name": "Windows",
  "rows": [
    "111101111",
    "111101111",
    "111101111",
    "111101111",
    "000000000",
    "111101111",
    "111101111",
    "111101111",
    "111101111"
  ]
}
```

### 规则与限制

- `"1"` 代表前景色点亮，`"0"` 代表底色。
- 点阵宽高范围：**宽 `1～16` 列、高 `1～11` 行**，每一行的字符串长度必须相同，且同一份配置里 `key` 不能重复。
- 固件会按 `6×6` 倍放大，自动居中绘制在左半边 `120×76` 的键帽区域内。
- `idleTimeoutMs` 目前必须保持 `0`（常显最近一次按下的按键，不自动超时熄灭）。

### 常见 HID 键码速查

如果你想往 `keys.json` 里新增几个常用键的大图标，可以直接照这个键码表配：

- 字母：`A`=`4` ～ `Z`=`29`
- 功能控制：`Enter`=`40`、`ESC`=`41`、`Backspace`=`42`、`Tab`=`43`、`Space`=`44`
- 导航键：`PgUp`=`75`、`Delete`=`76`、`PgDn`=`78`、方向右/左/下/上 = `79 / 80 / 81 / 82`
- 修饰键：左右 Win 都会统一映射成 `227`；`CTRL`（`224/228`）、`ALT`（`226/230`）、`ESC`（`41`）默认走清晰的大号英文文字路径（除非你在 `keys.json` 里主动为它们画了大图标）。
- 没在 `keys.json` 里单独画大图标的普通字母、数字、F1～F24 和标点，都会自动使用内置 5×7 像素字体放大渲染。

改好后用你的配置重新编译普通 IPS（或加上 `--lyrics` 编歌词版）：

```sh
python tools/build.py ips --stock inputs/ips-stock.bin --keys "/path/to/my-keys.json" --theme pink
```

## 2. 修改主题配色（`profiles/themes.json`）

`profiles/themes.json` 里内置了 `pink`（樱花粉）、`mint`（薄荷绿）、`mono`（墨水灰）三套配色。你可以直接修改这几个 Hex 色值，或者按同样格式新增一套你自己的主题 ID：

| 字段 | 管屏幕上的哪部分 |
| --- | --- |
| `background` | 整块屏幕底色、顶部状态栏背景 |
| `panel` | 左边大键帽框内部底色、机器人脸部底色 |
| `shell` | 下半屏大圆角外边框、机器人脚下阴影、歌词进度条底槽 |
| `ink` | 全部像素文字、时间、电量、键帽框描边与主体线条 |
| `accent` | 机器人身体、天线方块等点缀色 |
| `muted`（可选） | 歌词界面下一句预览歌词的颜色（不填默认沿用 `accent`） |

**重要提醒**：改完配色后，一定要**用同一个 `--theme` 参数同时生成配套 GIF 并编译 IPS 固件**，然后再把生成的 GIF 传进屏幕 S1 槽位，否则动态叠加出来的文字框底色会和背景 GIF 接不上：

```sh
python tools/assets.py --theme mint --out build/my-assets
python tools/build.py ips --stock inputs/ips-stock.bin --theme mint
```

## 3. 换成自己的动画或 GIF 角色

默认的小机器人动画是 `tools/assets.py` 用代码画的（没有外置精灵图），如果你更喜欢放自己的像素宠物或动画角色到右边区域，可以直接把自己的 GIF 传到 S1 槽位。上传前注意下面几条硬条件：

1. **分辨率必须严格为 `320×172`**，且总文件大小不能超过设备剩余可用空间（网页端上限限制 4MiB）。
2. **不要在 GIF 里提前画死时间、电量或左边按键框内容**，因为左边 `(40,57,120,76)` 以及顶部状态栏会在运行时被固件直接覆盖掉；右边留出你的角色动画、左边最好按主题留好对应 `panel` 色块会最协调。
3. **如果你同时使用了「歌词播放器扩展」**，自定义 GIF 还必须额外满足两条规则（`build.py` 也会在构建时检查）：
   - **每一帧都必须是 `320×172` 的完整帧**（导出 GIF 时关闭增量透明优化，使用全帧覆盖 `disposal=2`），因为切回按键页时固件需要截获一张完整的底图帧来还原画面。
   - **像素坐标 `(22, 39)` 的 RGB565 颜色不能和主题的 `background` 相同**——歌词固件靠检查这个标记点来确认当前缓冲区里确实是一张解码好的背景 GIF 帧，而不是未初始化的黑/纯底色块。

## 4. 进阶修改：移动 UI 坐标或扩展 5×7 字库

- **坐标与遮罩（`REGIONS`）**：5 个动态绘制区域（按键框、时钟、连接图标、电池图标、电量百分比）的坐标定义在 `tools/assets.py` 的 `REGIONS` 中，合计占用 `1378` 字节的 1-bit 位图遮罩缓冲。网页编辑器目前不支持直接拖拽布局；如果你要在源码里挪位置或改框大小，需要同步改 `REGIONS`、`base_frame` 底图画法以及 `firmware/ips*/native_ui.c` 中的边界校验，确保总遮罩不越界。
- **5×7 像素字库（`profiles/font.json`）**：存放了基础界面用的 ASCII 字符和小型符号点阵（不是系统 `.ttf` 字体，也不负责歌词页汉字显示）。固件里通过 `glyph_index()` 查表映射，增加新符号时需要同时更新 `tools/assets.py` 导出顺序和 C 代码里的索引映射。
