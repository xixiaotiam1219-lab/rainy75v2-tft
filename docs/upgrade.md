# 功能选择与旧版升级

本次源码版本为`0.2.0-alpha.4`。基础屏幕版可独立使用；歌词扩展内保留四套传统模板，另新增沉浸模板和可关闭的系统音量提示。三类用途不要求一起安装，也不需要上传三份字库。

## A 基础屏幕版

只需要大单键、时钟、电量、连接图标和原创机器人时，使用[基础版指南](usage.md)。日常显示不需要Node、字库或电脑后台，原生状态依设备可用于有线、2.4G和蓝牙。

新增沉浸、字体样式与音量功能不改变普通IPS显示流程。若只是旧公开机器人与边框闪烁，按[素材修复步骤](usage.md#已安装旧示例机器人出现闪烁时)覆盖最新同主题GIF即可尝试修复，不重刷主控、屏幕或字库。

校时仍依赖V7.1主控和实际RTC供电。完全断电导致计数归零后需要USB重新校时，不能承诺只校时一次永久保时。

## B 传统歌词播放器

安装步骤见[歌词指南](lyrics.md)。日常同步需要Windows后台和USB有线，控制网页可以关闭，后台独立运行、不依赖Codex。

| 模板 | 布局值 | 画面 |
| --- | --- | --- |
| 原版双行 | 0 | 20px当前句与下一句 |
| 04大字字幕（默认） | 1 | 20px标题＋40px当前句 |
| 大字聚焦 | 2 | 40px当前句＋20px下一句 |
| 双行大字 | 3 | 40px换行、长句按字形分页 |

传统模板保留时钟、电量和连接顶栏，歌词区域不显示机器人；按键页继续使用原生状态和原创机器人。四套模板共用20px Noto R75F/2字库，40px由屏幕整数两倍绘制。

已有旧LY1可以更新后台继续使用它支持的模板。旧双模板固件不发送布局2–4；从两套增加到四套或五套，需要更新歌词IPS。新后台按实际能力启用按钮，不把LY1能力号当作所有新增功能均可用的证明。

## C 沉浸播放器与音量增强

第五套模板（布局4）使用48×48小封面、封面取色雾面渐变、居中歌词和较高的进度条。此页按设计隐藏时钟、电量和连接顶栏；切回传统模板或按键页可查看原生状态。

沉浸歌词默认30px清晰，可在控制台选择20/30/40px及30px柔和边缘，仍复用同一份20px字库，不另外上传大字字模。

Windows系统音量变化时，可显示扬声器、百分比和伸缩音量条。默认仅沉浸页显示中央提示，短暂遮住歌词，最后一次变化约一秒后收起，歌词继续同步。可选择进度区、停留时间、所有页面，或关闭。普通歌词页使用中央提示，按键页在大键帽内显示并恢复最近键。

初始音量读取不弹动画；“预览提示”只显示当前数值，不修改系统音量。封面走OP28临时RAM通道、字体样式走OP29、音量走OP30，正常更新不写素材文件、不触发`Downloading`。首次安装字库和更换GIF仍会显示原厂下载提示。

## 我需要更新哪些部分？

下表中的“保留”以现有字体CRC、缓存GIF与目标构建兼容为前提。不要混用不同原厂输入或不同字体生成的固件。

| 当前情况与目标 | 电脑后台 | 屏幕IPS | 键盘主控 | 字库与GIF |
| --- | --- | --- | --- | --- |
| 已有基础版，只修旧公开机器人闪烁 | 不需要 | 保留 | 保留 | 只覆盖最新同主题机器人GIF |
| 已有兼容LY1，只改善切页卡顿 | 更新并重启 | 保留 | 保留 | 保留 |
| 已有旧LY1，增加沉浸、字体调整或音量 | 更新并重启 | 构建并安装本版歌词IPS | 匹配V7.1可保留 | CRC匹配原字库、合规缓存GIF可保留 |
| 已有本版沉浸/音量，只改字号、布局或提示设置 | 控制台保存 | 不重刷 | 不重刷 | 不重传 |
| 从基础版首次加歌词 | 安装Windows后台 | 核对芯片后安装歌词IPS | 需要匹配V7.1 | 首次上传同构建字库和匹配GIF |
| 更换字体内容 | 使用新字库索引 | 重新构建绑定新CRC | 兼容V7.1可保留 | 按固定FONT.BIN替换流程；GIF不因字号变化而重传 |

### 已有用户操作顺序

1. 在旧控制台退出后台，关闭WOBHub和其他驱动，避免抢占同一HID。
2. 保留个人设置、当前`FONT.BIN`、对应固件和恢复清单，拉取或下载新版源码，不把自己的素材覆盖成公开示例。
3. 如果只修切页卡顿，在仓库目录运行`npm install`、`npm run lyrics`即可，无需烧录。
4. 如果增加设备端功能，按[构建指南](build.md)使用匹配原厂输入和当前字库构建本版歌词IPS，按[歌词指南](lyrics.md)完成芯片核对和全字节校验。已有字库与新固件CRC一致时不重传。
5. 重启后台，打开它打印的本机地址，选择传统或沉浸模板并按需设置音量。默认不会把传统页自动改成沉浸页；Ctrl+F8循环按键页和设备支持的播放器模板。

源码目录移动或Node路径变化后，取消并重新启用登录自启，避免启动旧目录。WebHID校时、上传或烧录前仍需先退出后台。

## 版本、能力与验证

- `alpha.4`是源码版本。原厂主控`0x3F`与官方0.64 `0x40`使用独立输入SHA和地址表，补丁协议均可为V7.1。随仓HTML仍包含旧0x3F，不能当作0.64输入。
- 原厂屏幕0.02对应本项目L6；歌词IPS额外提供LY1，模板数、封面、字号和音量分别查询能力后启用。
- 编译、模型、烧录全字节校验、设备应答与用户视觉确认是不同证据，见[验证说明](validation.md)。不承诺固定帧率、输入延迟或全批次保时。
- PC歌词、封面与系统音量仍只支持USB。2.4G研究不作为本次发布功能，无线原生按键/电量通知不等于PC无线写屏已可用。
