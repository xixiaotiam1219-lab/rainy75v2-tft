03 / OPTIONAL LYRICS

歌词播放器扩展

基础屏幕版无需此步骤。歌词版需独立构建、屏内字库和 Windows 后台，详见歌词版安装与控制台。先退出其他后台和驱动页，再连接 USB 键盘。

仅在已安装 LY1 歌词扩展时接受字库写入。正常使用无需逐句上传图片；歌词后台从 npm run lyrics 启动，Ctrl＋F8 切换界面。
