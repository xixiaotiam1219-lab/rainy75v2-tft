## 首次安装

1. 用 USB 数据线连接键盘本体，切到有线模式，退出 WOBHub 和其他驱动。
2. 选「桌宠与按键」或「再加一个播放器」，点击「连接键盘」。
3. 工作台检查后会显示本次要安装的内容。核对后点「开始安装」。
4. 浏览器要求重新授权时，点页面上的连接按钮并选择升级设备。主控和屏幕是不同设备，可能需要分别授权。
5. 安装完成后检查屏幕。选择了播放器的用户，再点「启动歌词后台」。

基础页可脱离电脑使用。歌词、封面和系统音量同步需要 Windows 后台与 USB 连接；网页可关闭。`Ctrl + F8` 循环切换按键页与播放器。

## 换外观与日常使用

- **桌宠**：在「桌宠动图」导入 GIF 或图片，调整位置，点「使用这张动图」，再进入安装页。未明确选择替换的现有动画会保留。
- **AI 定制桌宠**：展开「让 AI 帮我设计」，填入想法，一键复制带当前配色的提示词。把 AI 给的 GIF / PNG 导回工作台即可。
- **配色**：在「主题与排版」选择预设或调色。改屏幕配色需要更新配套屏幕固件与素材。
- **播放器布局、字号、音量**：可在后台控制台调整，无需重刷固件。
- **校时**：在「安装与维护」展开「日常维护」。完全断电后可能需要重新校时。
- **登录自启**：在「歌词后台」打开「登录时自动启动」。请固定存放发布包；移动目录后重新启用。

默认页只显示常用操作。更多解释点「帮助」；硬件参数、日志、手动文件和完整清单均可展开。

## 无法连接或显示异常

- 工作台提示后台运行时，先点「暂停歌词后台」，停止成功后再连接。后台未响应时，不会声称 USB 已释放。
- 字库会等待屏幕初始化后再检查，已有可用的配套 `FONT.BIN` 会直接复用。字库步骤失败时先点「恢复显示并检查字库」，通过后点「再试一次这一步」，无需重刷已完成的固件。
- 浏览器选不到键盘时，确认使用 Chrome / Edge、USB 数据线与有线模式，退出其他驱动后重试。2.4G 接收器不能用来烧录。
- 已有自定义屏幕会自动采用更新流程。原厂主控版本能读到时自动选择，无法读取时再按 WOBHub 显示的版本核对。
- 安装后仍是旧画面时，在官方驱动中确认屏幕为 **GIF 播放 / 槽位 1**，然后退出官方驱动。
- 连接/写入失败时，先查看页面当步错误与展开的记录，再参考 [恢复与救砖](RECOVERY-恢复与救砖.md)。

## 发布包里的入口

日常只需根目录的工作台入口。`Windows便携后台` 中的脚本可单独启动、打开控制台或退出后台。配置保存在它的 `data` 文件夹；主控、屏幕与恢复镜像位于「固件与素材」。

直接双击单文件 HTML 可离线预览与制作素材；需要在页面中管理后台时，使用上面的 CMD 入口。
