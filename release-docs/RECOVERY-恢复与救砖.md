# Rainy75 V2 TFT 恢复原厂与救砖指南

本指南用于在固件测试后需要退回原厂状态，或在刷写异常、副屏花屏、无法正常进入桌面时进行安全恢复。基础日常用法请参阅 [使用说明](README-使用说明.md)。

---

## 1. 关于恢复镜像的重要声明

发布包 ``固件与素材\restore-images\`` 目录中的恢复固件（例如 `main-064-restore.bin`、`main-063beta1-restore.bin`、`ips-restore.bin`）：

1. **并非实机 Flash 回读备份**：这些镜像不是从某台物理键盘芯片直接读出的 dump，而是使用与各声明版本对应的官方原厂固件输入，按目标 Flash 分区布局与大小重建并经过清单 SHA-256 校验的恢复包。详见 ``固件与素材\restore-images\RESTORE-NOTICE.txt``。
2. **请按原始主控批次选择恢复镜像**：
   - 原厂为 `0.64` 主控的键盘请使用 `main-064-restore.bin`。
   - 原厂为 `0.63-beta1` 主控的键盘请使用 `main-063beta1-restore.bin`。
   - 副屏原厂恢复请使用 `ips-restore.bin`。

---

## 2. 常见异常排查（无需立即刷机）

在判断为“变砖”之前，建议先逐项排查以下高频问题：

### 情况 A：浏览器工作台连不上键盘 / WebHID 授权后无响应
- **原因 1（最常见）**：``Windows便携后台`` 仍在后台占用键盘 HID 接口。
  - **解决**：在通过 ``1-打开工作台（推荐点我）.cmd`` 打开的工作台右上角点击**停止后台**，或手动双击 ``Windows便携后台\退出后台.cmd``，等待 1~2 秒后在浏览器重试。
- **原因 2**：处于蓝牙或 2.4G 无线模式，或使用了不稳定的 USB Hub。
  - **解决**：切换开关到**有线模式**，直接插在主板/笔记本原生 USB 口上，重新拔插一次。
- **原因 3**：旧版驱动或官方驱动客户端同时在后台运行。
  - **解决**：在任务管理器中退出官方键盘驱动或其它 HID 监控工具后再使用 WebHID。

### 情况 B：副屏显示乱码、空白或开机卡旧画面
1. 先确认刷写的副屏模式与步骤是否一致：若使用 `ips-lyrics` 歌词固件，需确保配套 `FONT.BIN` 已就绪。已有可用字库会直接复用。
2. 若字库上传提示「状态 4」，表示素材存储空间不足。不要重复上传或盲目删除现有文件。先停止歌词后台和官方驱动，点击「恢复显示并检查字库」。检查通过后仅重试当前步骤；检测到已有但不可用的 `FONT.BIN` 时，需核对版本，使用对应旧字库备份走明确替换流程。
3. `OP2 / ID…` 超时且最后应答为 `status:193,value:0`，表示未收到匹配的暂停确认，该应答可能来自其他查询；`legacyChecksum:true` 表示兼容的旧式校验，不代表字库损坏。先停止其他后台，恢复显示并检查字库。此错误本身不要求进入 IAP。
4. 在工作台确认当前主控是否与所选副屏方案兼容，重新按工作台向导写入对应副屏镜像和 GIF 资产。

## 3. 退回原厂固件的步骤

### 情况 1：键盘仍可通过有线 USB 正常识别（软恢复）
1. 退出 ``Windows便携后台``（运行 ``退出后台.cmd``）及所有官方驱动。
2. 使用 ``1-打开工作台（推荐点我）.cmd`` 打开工作台。
3. 连接键盘后，在刷机/恢复区选择：
   - 与你键盘批次一致的主控恢复镜像（`main-064-restore.bin` 或 `main-063beta1-restore.bin`），和/或
   - 副屏恢复镜像（`ips-restore.bin`）。
4. **刷写期间切勿拔线、休眠或关闭浏览器标签页**，等待进度完成且键盘自行重启。

### 情况 2：正常模式和升级模式均无法识别

本项目尚未核实各批次的强制恢复按键、触点或 ROM ISP 接线方法。不能把发布包中的应用区恢复镜像当作整片 Flash 备份，也不能据此猜测 ISP 起始地址。

如果能识别为主控或屏幕 IAP，仍可按上面的软恢复流程选择对应目标。若连 IAP 也无法识别，请向厂家确认该批次的强制恢复方法，或交由具备调试器的维修人员处理；不要按猜测短接主板。

---

## 4. 校验受损或疑似文件损坏

在刷写前怀疑下载包不完整时，请勿强行刷入，可先在 PowerShell 中核对根目录 ``SHA256SUMS.txt``：

```powershell
Get-FileHash .\固件与素材\restore-images\ips-restore\rainy75v2-ips-restore.bin -Algorithm SHA256
```

将输出结果与 ``SHA256SUMS.txt`` 中对应条目比对，不一致请重新获取完整发布包。
